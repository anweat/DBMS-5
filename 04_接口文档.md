# 数据库管理系统（DBMS）接口文档

**版本**：3.1
**日期**：2026-05-06
**语言**：C++17
**通信方式**：C++ 类直接调用（CLI 层 / Qt 前端 → 引擎层）

---

## 概述

所有交互通过 **函数调用** 完成。CLI 层（`src/cli/`）和 Qt 前端（`src/ui/`）都直接或间接持有 `DBEngine`，调用其方法获得结构化结果。CLI 由 `Formatter` 渲染到终端，Qt 前端将 `QueryResult` 渲染到表格控件和状态栏。
所有调用均为**同步**，无 async/await。

### SQL 查询能力

#### SELECT 查询
- **单表查询**：`SELECT * FROM table` 及当前支持的查询子句
- **多表查询**：支持逗号分隔多表 `FROM table1 alias1, table2 alias2`，语义为隐式内连接
- **显式内连接**：支持 `INNER JOIN ... ON` 和省略 `INNER` 的 `JOIN ... ON`，可链式连接多个表
- **表别名**：支持 `AS` 关键字或省略 `AS` 的别名形式
- **qualified 列名**：支持 `table.column` 或 `alias.column` 形式的限定列名
- **WHERE 条件**：
  - 列到字面量比较：`WHERE id = 1`
  - 列到列比较：`WHERE users.id = orders.user_id`（支持多表连接）
  - 支持 `AND`、`OR`、`NOT`、`IN`、`LIKE`、`BETWEEN`、`IS NULL` 等运算符
- **ORDER BY**：支持 qualified 列名，如 `ORDER BY table.column DESC`
- **GROUP BY / HAVING**：支持分组和分组条件过滤
- **聚合函数**：`COUNT`、`SUM`、`AVG`、`MAX`、`MIN`
- **LIMIT / OFFSET**：分页查询
- **DISTINCT**：去重

#### 当前不支持但已列入后端规划
- 外连接语法，包括 `LEFT JOIN`、`RIGHT JOIN`、`FULL OUTER JOIN`
- `IN (SELECT ...)` 子查询，目前 `IN` 仅用于字面量列表
- 存储过程：`CREATE PROCEDURE`、`CALL`、`DROP PROCEDURE`
- 触发器：`CREATE TRIGGER`、`DROP TRIGGER`，以及 INSERT/UPDATE/DELETE 执行钩子

#### 其他 DML
- **INSERT**：支持单行和多行插入
- **UPDATE**：支持 WHERE 条件更新
- **DELETE**：支持 WHERE 条件删除

#### DDL
- 数据库：`CREATE DATABASE`、`DROP DATABASE`、`SHOW DATABASES`、`USE`
- 表：`CREATE TABLE`、`DROP TABLE`、`SHOW TABLES`、`DESCRIBE`、`ALTER TABLE`
- 索引：`CREATE INDEX`（自动回填现有记录）、`DROP INDEX`

#### 事务
- `BEGIN TRANSACTION`、`COMMIT`、`ROLLBACK`
- Write-Ahead Log (WAL) 支持崩溃恢复

#### 安全
- 用户管理：`CREATE USER`、`DROP USER`、`CONNECT`
- 权限管理：`GRANT`、`REVOKE`（支持 SELECT、INSERT、UPDATE、DELETE、ALL）

#### 备份/恢复
- `BACKUP DATABASE <name> TO '<file>'`：导出数据库为 SQL 文件
- `RESTORE DATABASE <name> FROM '<file>'`：从 SQL 文件恢复数据库

### 统一结果类型

```cpp
// src/types.h

#pragma once
#include <string>
#include <vector>
#include <variant>
#include <optional>

// 字段类型
enum class FieldType { INTEGER, DOUBLE, BOOL, VARCHAR, DATETIME };

// 字段元信息
struct ColumnMeta {
    std::string name;
    FieldType   type;
};

// 单行数据（每格为 variant，支持多类型）
using FieldValue = std::variant<std::monostate, int64_t, double, bool, std::string>;
using Row        = std::vector<FieldValue>;

// 错误码
enum class ErrorCode {
    DB_ALREADY_EXISTS, DB_NOT_FOUND, DB_SYSTEM, DB_NAME_INVALID,
    TABLE_ALREADY_EXISTS, TABLE_NOT_FOUND, TABLE_NAME_INVALID,
    COLUMN_NOT_FOUND, COLUMN_ALREADY_EXISTS, COLUMN_INVALID,
    CONSTRAINT_VIOLATION, DUPLICATE_KEY, FOREIGN_KEY_VIOLATION,
    TRANSACTION_NOT_FOUND, TRANSACTION_CONFLICT,
    PERMISSION_DENIED, SQL_SYNTAX_ERROR, FILE_IO_ERROR, UNKNOWN_ERROR
};

struct DBError {
    ErrorCode   code;
    std::string message;
};

// 查询结果
struct QueryResult {
    enum class Type { SELECT, DDL, DML, ERROR } type;

    // SELECT 时填充
    std::vector<ColumnMeta> columns;
    std::vector<Row>        rows;
    int                     rowCount    = 0;

    // DML 时填充
    int                     affectedRows = 0;
    int64_t                 insertId     = -1;

    // 通用
    std::string             message;
    std::optional<DBError>  error;
    long long               elapsedMs   = 0; // 执行耗时（毫秒）
};
```

## 1. 引擎主入口（DBEngine）

```cpp
// src/engine/DBEngine.h

#pragma once
#include "types.h"
#include <string>

struct Session {
    std::string sessionId;
    std::string currentDatabase; // 空字符串表示未选库
    std::string transactionId;   // 空字符串表示无活跃事务
    std::string user;            // 当前登录用户
};

class DBEngine {
public:
    explicit DBEngine(const std::string& dataDir);

    /** 执行任意 SQL 语句（单条，不含末尾分号） */
    QueryResult execute(const std::string& sql, Session& session);

    /** 开启事务 */
    void beginTransaction(Session& session);

    /** 提交事务 */
    void commit(Session& session);

    /** 回滚事务 */
    void rollback(Session& session);
};
```

> CLI REPL 和 Qt 前端均通过 `engine.execute(sql, session)` 驱动所有操作，无需感知内部模块。

### 2.2 TableManager

```cpp
// src/engine/storage/TableManager.h

#pragma once
#include "types.h"
#include <string>
#include <vector>
#include <optional>

struct ColumnDefinition {
    std::string name;
    FieldType   type;
    int         length        = 255; // VARCHAR 长度
    bool        nullable      = true;
    std::string defaultValue;        // 空字符串表示无默认值
    bool        primaryKey    = false;
    bool        autoIncrement = false;
    bool        unique        = false;
};

struct TableDefinition {
    std::string                  name;
    std::vector<ColumnDefinition> columns;
};

class TableManager {
public:
    explicit TableManager(const std::string& dataDir);

    /** 列出指定数据库下的所有表名 */
    std::vector<std::string> listTables(const std::string& database);

    /** 读取表结构定义（返回 nullopt 若不存在） */
    std::optional<TableDefinition> describeTable(const std::string& database,
                                                  const std::string& table);

    /** 创建表（写入 .tdf 文件） */
    void createTable(const std::string& database, const TableDefinition& def);

    /** 删除表（删除 .tdf 与 .trd 文件） */
    void dropTable(const std::string& database, const std::string& table);

    /** 添加字段 */
    void addColumn(const std::string& database, const std::string& table,
                   const ColumnDefinition& col);

    /** 修改字段 */
    void modifyColumn(const std::string& database, const std::string& table,
                      const std::string& colName, const ColumnDefinition& newDef);

    /** 删除字段 */
    void dropColumn(const std::string& database, const std::string& table,
                    const std::string& colName);
};
```

## 5. Qt 前端接口约定

Qt 前端保持轻量适配层，不重新解析 SQL，不直接访问 `data/` 文件。

```cpp
// src/ui/QtSessionAdapter.h

#pragma once
#include "../engine/DBEngine.h"
#include "../types.h"
#include <string>

class QtSessionAdapter {
public:
    explicit QtSessionAdapter(const std::string& dataDir);

    /** 执行 UI 输入的 SQL，并返回结构化 QueryResult 供表格渲染 */
    QueryResult executeSql(const std::string& sql);

    /** 返回当前会话状态，用于状态栏显示 */
    const Session& session() const;

private:
    DBEngine engine_;
    Session  session_;
};
```

Qt 渲染规则：

- `QueryResult::columns` 映射为表头。
- `QueryResult::rows` 映射为表格单元格。
- `QueryResult::affectedRows` 和 `elapsedMs` 显示在状态栏。
- `QueryResult::error` 显示在错误提示区域或弹窗。

## 6. 错误码列表

| 错误码 | 含义 |
|---|---|
| `DB_ALREADY_EXISTS` | 数据库已存在 |
| `DB_NOT_FOUND` | 数据库不存在 |
| `DB_SYSTEM` | 系统数据库不可操作 |
| `DB_NAME_INVALID` | 数据库名不合法 |
| `TABLE_ALREADY_EXISTS` | 表已存在 |
| `TABLE_NOT_FOUND` | 表不存在 |
| `TABLE_NAME_INVALID` | 表名不合法 |
| `COLUMN_NOT_FOUND` | 字段不存在 |
| `COLUMN_ALREADY_EXISTS` | 字段已存在 |
| `COLUMN_INVALID` | 字段定义不合法 |
| `CONSTRAINT_VIOLATION` | 完整性约束违反 |
| `DUPLICATE_KEY` | 主键/唯一键冲突 |
| `FOREIGN_KEY_VIOLATION` | 外键约束违反 |
| `TRANSACTION_NOT_FOUND` | 事务不存在 |
| `TRANSACTION_CONFLICT` | 事务操作冲突 |
| `PERMISSION_DENIED` | 权限不足 |
| `SQL_SYNTAX_ERROR` | SQL 语法错误 |
| `FILE_IO_ERROR` | 文件读写失败 |
| `UNKNOWN_ERROR` | 未知错误 |

## 7. 典型调用流程

```
用户输入 SQL → REPL 检测到 `;` 结尾
       │
       ▼
MetaCommandHandler::handle()    ← 若是 \help 等元命令直接处理
       │ 非元命令
       ▼
Lexer::tokenize(sql)            → vector<Token>
       │
       ▼
Parser::parse(tokens)           → ASTNode
       │
       ▼
Executor::execute(ast, session) → QueryResult
       │
       ▼
Formatter::format(result)       → 终端字符串（ANSI 色彩）
       │
       ▼
打印到 stdout，显示下一个提示符
```

### Qt 调用流程

```
用户在 Qt 输入 SQL 并点击执行
       │
       ▼
QtSessionAdapter::executeSql(sql)
       │
       ▼
DBEngine::execute(sql, session)
       │
       ▼
QueryResult
       │
       ├── SELECT：渲染到 QTableWidget / QTableView
       ├── DML/DDL：显示 affectedRows / message
       └── ERROR：显示 error.message
```
