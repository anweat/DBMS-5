# DBMS-5 用户使用手册

## 1. 环境准备

推荐在 Windows 下使用 MSYS2 UCRT64 工具链。

```powershell
cmake --preset windows-msys2-ucrt64
cmake --build --preset windows-msys2-ucrt64
```

如果运行测试或程序时提示缺少运行时 DLL，请先加入 MSYS2 路径：

```powershell
$env:PATH='C:\msys64\ucrt64\bin;' + $env:PATH
```

## 2. 启动 CLI

```powershell
.\build-windows\dbms.exe
```

首次使用 root 登录：

```sql
CONNECT 'root' IDENTIFIED BY 'root';
```

常用元命令：

| 命令 | 说明 |
|---|---|
| `\help` | 查看帮助 |
| `\connect root root` | 登录 |
| `\status` | 查看当前用户、数据库和事务状态 |
| `\databases` | 查看数据库 |
| `\tables` | 查看当前库表 |
| `\desc table_name` | 查看表结构 |
| `\quit` | 退出 |

## 3. CLI 基本操作示例

```sql
CONNECT 'root' IDENTIFIED BY 'root';
CREATE DATABASE demo;
USE demo;

CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(64) NOT NULL,
    age INTEGER DEFAULT 0
);

INSERT INTO users (name, age) VALUES ('Alice', 20);
INSERT INTO users (name, age) VALUES ('Bob', 22);

SELECT * FROM users;
UPDATE users SET age = 21 WHERE name = 'Alice';
DELETE FROM users WHERE name = 'Bob';
```

## 4. 启动 Qt 界面

可使用脚本：

```powershell
.\run_qt.bat
```

或直接运行构建产物中的 Qt 程序。

## 5. Qt 界面操作

| 操作 | 步骤 |
|---|---|
| 登录 | 在登录区输入用户名和密码，点击连接 |
| 选择数据库 | 在左侧树形图点击数据库，或执行 `USE dbname` |
| 执行 SQL | 在 SQL 编辑区输入语句，点击执行按钮 |
| 查看结果 | SELECT/SHOW 结果显示在结果表格中 |
| 查看表数据 | 点击左侧表、列或索引节点，TableData 显示对应表 |
| 创建表 | 点击数据库节点，在 Admin/Structure 中添加字段行并提交 |
| 删除表 | 聚焦数据库或表后，在 Admin 操作区执行删除表 |
| 建索引 | 聚焦数据库或表后，选择表与字段创建索引 |
| 编辑数据 | 在 TableData 中新增、删除或修改行，最后点击保存 |
| 管理权限 | 在 Admin/Users 中选择用户和对象，勾选权限后授权或回收 |

## 6. 权限说明

默认超级用户：

| 用户名 | 密码 | 权限 |
|---|---|---|
| root | root | 所有数据库和表的全部权限 |

普通用户需要 root 授权后才能访问对象：

```sql
CREATE USER alice IDENTIFIED BY 'alice123';
GRANT SELECT, INSERT ON demo.users TO alice;
REVOKE INSERT ON demo.users FROM alice;
```

## 7. 事务操作

```sql
BEGIN;
UPDATE users SET age = 30 WHERE name = 'Alice';
ROLLBACK;

BEGIN;
UPDATE users SET age = 31 WHERE name = 'Alice';
COMMIT;
```

## 8. 常见问题

| 问题 | 处理方式 |
|---|---|
| 无法执行 SQL | 确认已经登录，并选择了数据库 |
| 普通用户查询失败 | 检查是否已被授予对应表的 SELECT 权限 |
| Qt 保存表格失败 | 查看界面错误提示，常见原因是主键重复、非空列为空或类型不匹配 |
| Windows 运行时报 DLL 错误 | 将 `C:\msys64\ucrt64\bin` 加入 PATH |
| 表结构修改后数据异常 | 优先通过 Qt 的统一提交或标准 ALTER TABLE 操作，避免直接修改数据文件 |
