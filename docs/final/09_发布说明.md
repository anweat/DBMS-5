# DBMS-5 发布说明

## 1. 发布内容

本次发布面向课程最终验收，包含源码、测试、最终文档、汇报 PPT、演示脚本和 Qt 录屏。

| 类别 | 路径 | 说明 |
|---|---|---|
| 源码 | `src/` | DBEngine、Lexer、Parser、Executor、Storage、CLI、Qt UI |
| 测试 | `tests/` | lexer、integration、security、comprehensive、CLI、Qt UI 测试 |
| 最终文档 | `docs/final/` | 启动、关闭、需求、设计、测试、用户手册、演示方案、录屏脚本、发布说明 |
| 规划文档 | `docs/planning/` | 开发规划、技术选型、分工计划、接口文档和原始需求材料 |
| 技术参考 | `docs/reference/` | 后端调用链路、GitHub 提交策略、仓库保护设置 |
| 演示材料 | `demos/` | Qt 录屏、SQL 全覆盖脚本、CLI 逐句脚本、恢复脚本 |
| 汇报 PPT | `docs/final/DBMS-5_项目汇报.pptx` | 按成员分工组织的最终展示材料 |

## 2. 推荐入口

## 4. 复现命令

```powershell
cmake --preset windows-msys2-ucrt64
cmake --build --preset windows-msys2-ucrt64
ctest --preset windows-msys2-ucrt64 --output-on-failure
```

CLI 演示：

```text
source demos/full_acceptance_demo.sql
source demos/cli_step_demo.sql
```

Qt 演示：

```powershell
.\run_qt.bat
```
