# DBMS-5 测试报告

## 1. 测试目标

验证 DBMS-5 在核心 SQL、存储、事务、权限、Qt 界面和跨平台构建方面满足最终交付要求，重点检查功能正确性、错误处理、数据持久化和界面可操作性。

## 2. 测试环境

| 项目 | 环境 |
|---|---|
| 操作系统 | Windows |
| 编译工具 | CMake、Ninja、MSYS2 UCRT64 g++ |
| 语言标准 | C++17 |
| GUI 框架 | Qt Widgets |
| 测试框架 | CTest + 项目内自定义测试程序 |

## 3. 测试命令

```powershell
cmake --build build-qt-tests --target test_qt_ui qt_demo_record
$env:QT_QPA_PLATFORM='offscreen'
.\build-qt-tests\test_qt_ui.exe

cmake --build --preset windows-msys2-ucrt64
$env:PATH='C:\msys64\ucrt64\bin;' + $env:PATH
ctest --test-dir build-windows --output-on-failure
```

测试结果：`ctest` 共 6 个测试，全部通过；Qt UI 冒烟测试通过。

## 5. 缺陷修复记录

| 问题 | 修复 |
|---|---|
| Qt Admin 按钮过多、上下文不清晰 | 拆分对象、结构、用户权限页，跟随树形图聚焦 |
| 建表需要手写 SQL | 改为字段表格，统一提交 |
| 点击列/索引不显示表数据 | 树形图信号补充对应表名，自动刷新 TableData |
| 字符串在 macOS/Windows 识别存在差异 | Executor、ExprEvaluator、RecordManager 增加类型转换兜底 |
| Windows ctest 找不到运行时 DLL | 测试前补充 MSYS2 UCRT64 PATH |

## 6. 测试结论

项目核心功能、权限控制、跨平台兜底和 Qt 管理界面均已通过当前测试。剩余风险主要集中在超大数据量性能、复杂 SQL 兼容性和更多平台组合的持续集成覆盖。
