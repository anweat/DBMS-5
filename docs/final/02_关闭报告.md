## 2. 最终实现功能

### 2.1 数据定义功能

- 创建、删除、切换数据库。
- 创建、删除、修改表结构。
- 添加、修改、删除字段。
- 创建和删除索引。
- 查看数据库、表、字段、索引等元信息。

### 2.2 数据操作功能

- 插入、查询、更新和删除记录。
- 支持 WHERE 条件、AND/OR、字段比较和字面量比较。
- 支持排序、分组、限制行数、去重和聚合函数。
- 支持多表查询、表别名和 `INNER JOIN ... ON`。

### 2.3 数据完整性与安全性

- 支持 PRIMARY KEY、NOT NULL、UNIQUE、DEFAULT、AUTO_INCREMENT。
- 支持外键参照完整性检查。
- 支持 root 超级用户和普通用户。
- 支持针对库表对象的 SELECT、INSERT、UPDATE、DELETE、ALL 授权与回收。

### 2.4 事务与恢复

- 支持显式事务开始、提交和回滚。
- 使用内存 Undo Log 支持运行时回滚。
- 使用 WAL 记录操作日志，重启时撤销未提交事务。

### 2.5 Qt 图形界面

- 左侧树形图展示数据库、表、列、索引。
- 点击数据库时聚焦数据库管理页，可建表、删表、建索引。
- 点击表、列或索引时自动显示对应表结构和数据。
- Admin 面板拆分为对象信息、结构编辑、权限管理等上下文页面。
- 表结构编辑采用表格方式增删列，统一提交，避免硬 SQL 编写。
- 表数据编辑支持新增行、删除行、保存修改和错误提示。

## 3. 创新点

| 创新点 | 说明 |
|---|---|
| 自研 SQL 处理链路 | 从词法、语法、AST 到执行器均由项目实现，便于展示 DBMS 内部机制 |
| 文件级存储引擎 | 使用 `.tdf`、`.trd`、`.tix` 等文件组织元数据、记录和索引 |
| B 树索引实现 | 基于 CLRS 思路实现可持久化的 B 树索引结构 |
| 事务与 WAL 结合 | 兼顾运行时回滚和异常退出后的恢复能力 |
| 权限感知 GUI | Qt 树形目录和管理面板会结合当前对象展示操作和权限选项 |
| 表格化建表体验 | GUI 中使用 name/type/Not Null/Primary Key 表格编辑表结构，降低硬 SQL 门槛 |
| 跨平台字符串兜底 | 对 Windows/macOS 不同输入和 QVariant 字符串识别差异做类型转换兜底 |

## 6. 开发阶段复盘

项目实际按 12 周推进。前 4 周以方案确定为主，重点完成需求分析、技术选型、模块划分和接口约定；中间 4 周集中实现后端数据库内核，完成 SQL 解析、执行、存储、索引、事务和权限；最后 4 周完成 CLI/Qt 前端、管理界面优化、测试、录屏和文档汇总。

| 阶段 | 主要产出 | 复盘 |
|---|---|---|
| Week 1-4 方案阶段 | 需求分析、技术路线、架构设计、分工计划 | 前期把模块边界和接口定清楚，后续协作更顺畅 |
| Week 5-8 后端阶段 | DBEngine、Parser、Executor、Storage、事务、权限 | 后端链路复杂，集成测试对发现语义和存储问题很关键 |
| Week 9-12 前端交付阶段 | CLI、Qt UI、Admin 优化、录屏、最终文档和 PPT | 前端把后端能力可视化后，项目展示效果明显提升 |
