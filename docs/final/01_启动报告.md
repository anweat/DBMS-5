# DBMS-5 项目启动报告

## 1. 项目概述

DBMS-5 是一个基于 C++17 自主实现的轻量级关系型数据库管理系统。项目目标是在不依赖外部数据库内核的前提下，完成从 SQL 输入、词法语法分析、查询执行、文件存储、事务、安全控制到可视化管理界面的完整闭环。

项目交付形态包括：

| 交付项 | 说明 |
|---|---|
| 数据库内核 | 支持数据库、表、记录、索引、事务、权限等核心能力 |
| CLI 终端 | 提供交互式 SQL REPL、元命令、结果表格展示 |
| Qt 桌面界面 | 提供登录、库表树、SQL 编辑、结果表、表数据编辑、管理面板 |
| 测试用例 | 覆盖词法、语法、执行、权限、集成和 Qt UI 冒烟测试 |
| 文档与演示 | README、接口文档、最终报告、演示视频和汇报 PPT |

## 2. 项目目标

| 目标类型 | 目标内容 |
|---|---|
| 基础目标 | 可创建/删除数据库和表，可执行基础 SQL，可持久化数据 |
| 核心目标 | 支持 INSERT、SELECT、UPDATE、DELETE 和 WHERE 条件查询 |
| 高级目标 | 支持索引、事务、完整性约束、用户与权限管理 |
| 展示目标 | 提供 CLI 和 Qt 双入口，便于演示和普通用户操作 |
| 质量目标 | 保证 Windows/macOS/Linux 构建适配，补充自动化测试 |

## 6. 风险与应对

| 风险 | 影响 | 应对措施 |
|---|---|---|
| SQL 解析范围扩大 | Parser 和 AST 改动大 | 先冻结核心 SQL 子集，再分阶段扩展 JOIN、聚合等能力 |
| 二进制文件格式复杂 | 数据落盘和迁移容易出错 | 表定义、记录、索引分文件管理，配合集成测试验证 |
| 前后端接口耦合 | Qt 可能绕过 DBMS 内核 | Qt 统一通过 DBEngine::execute 调用，复用 QueryResult |
| 跨平台差异 | Windows/macOS 对字符串与运行时环境处理不同 | 增加字符串类型兜底、MSYS2 preset 和 macOS 适配 |
| 测试覆盖不足 | 最终演示风险高 | 形成 lexer/parser/executor/security/Qt 多层测试 |

## 7. 启动结论

项目启动时目标明确、模块边界清晰，采用“解析层-执行层-存储层-界面层”的分层方式降低协作复杂度。最终交付重点放在可运行、可演示、可测试的完整 DBMS 闭环上。
