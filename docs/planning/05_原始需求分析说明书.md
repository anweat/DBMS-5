## 2 总体概述

### 2.1 软件概述

#### 2.1.1 项目介绍

数据库管理系统（DBMS）是用于**建立、使用、维护数据库**的核心软件，统一管理与控制数据库，保障数据安全与完整性。

- 支持多用户、多应用并发访问与操作

- 提供**DDL（数据定义语言）与DML（数据操作语言）**

- 实现数据库创建、修改、查询、权限控制等能力

#### 2.1.2 产品环境介绍

- 运行环境：Windows桌面窗口程序

- 数据存储：操作系统文件系统

- 网络能力：支持客户端/服务端通讯

### 2.2 软件功能

系统分为**10大核心模块**：

|模块名称|模块描述|
|---|---|
|数据库管理|数据库创建/删除，管理数据库定义文件|
|表管理|表的增/删/改，管理表描述文件|
|字段管理|字段的增/删/改，管理字段定义文件|
|数据管理|数据插入、更新、查询、删除|
|索引管理|建立索引，优化查询效率|
|客户端管理|C/S架构，支持多客户端连接多服务端|
|事务管理|实现数据库事务控制|
|完整性管理|完整性约束检查与管理|
|数据库维护|数据库备份与还原|
|安全性管理|用户管理、权限管理|
### 2.3 用户特征

- **数据库管理员**：具备数据库专业知识，负责安装、部署、创建、维护

- **客户端用户**：具备基础软件操作与数据库知识，可完成数据增删改查

### 2.4 假设和依赖关系

- 主流运行环境：Windows操作系统

- 扩展要求：支持其他操作系统的可移植适配

## 3 具体需求

### 3.1 系统用例

提供DBMS顶层系统用例图，覆盖全部核心操作入口。

### 3.2 数据库管理

#### 3.2.1 创建数据库

- 对应SQL：`CREATE DATABASE <database name>`

- 数据库类型：系统库（Ruanko，不可删除）、用户库

- 输入：库名、存储路径、创建时间、类型

- 处理：

    1. 校验库名（≤128字符、不重复）

    2. 写入/追加到`ruanko.db`

- 输出：更新`ruanko.db`数据库描述文件

#### 3.2.2 删除数据库

- 对应SQL：`DROP DATABASE <database name>`

- 约束：系统库不可删、有用户连接不可删

- 处理：校验存在→校验连接→删除库信息→删除相关文件

- 输出：更新`ruanko.db`

### 3.3 表管理

#### 3.3.1 创建表

- 对应SQL：`CREATE TABLE <table name>`

- 输入：库名、表名、文件路径、创建时间等

- 处理：

    1. 校验表名（≤128字符、不重复）

    2. 生成4个表文件：`.tdf`/`.tic`/`.trd`/`.tid`

    3. 写入`[库名].tb`

- 输出：更新表描述文件

#### 3.3.2 修改表

- 对应SQL：`ALTER TABLE <table name> ...`

- 处理：查找表信息→更新修改时间→刷新表信息

- 输出：更新`[库名].tb`

#### 3.3.3 删除表

- 对应SQL：`DROP TABLE <table name>`

- 处理：查找表→删除表信息→删除关联文件

- 输出：更新`[库名].tb`

### 3.4 字段管理

#### 3.4.1 添加字段

- 对应SQL：`ALTER TABLE ... ADD COLUMN ...`

- 输入：库名、表名、字段名、类型、约束等

- 处理：校验字段有效性→更新表定义文件

- 输出：`[表名].tdf`

#### 3.4.2 修改字段

- 对应SQL：`ALTER TABLE ... MODIFY COLUMN ...`

- 处理：校验存在→更新字段→同步索引与记录

- 输出：更新`.tdf`/`.trd`/`.tid`

#### 3.4.3 删除字段

- 对应SQL：`ALTER TABLE ... DROP COLUMN ...`

- 处理：校验存在→移除关联索引→更新字段与记录

- 输出：更新`.tdf`/`.trd`/`.tid`

### 3.5 数据管理

#### 3.5.1 插入记录

- 对应SQL：`INSERT INTO ... VALUES ...`

- 处理：读字段→校验完整性→赋值→写入`.trd`

- 输出：`[表名].trd`

#### 3.5.2 更新记录

- 对应SQL：`UPDATE ... SET ... WHERE ...`

- 处理：校验约束→按主键定位→更新记录

- 输出：更新记录文件

#### 3.5.3 查询记录

- 对应SQL：`SELECT * FROM ... WHERE ...`

- 处理：读表信息→加载记录→返回并展示

- 输出：界面视图显示结果

#### 3.5.4 删除记录

- 对应SQL：`DELETE FROM ... WHERE ...`

- 处理：定位记录→删除→同步索引

- 输出：更新`.trd`/`.tid`

### 3.6 索引管理

对关键字段建立索引，用于查询加速，支持功能扩展。

### 3.7 客户端管理

C/S架构，客户端可连多服务器，服务端支持多客户端。

### 3.8 事务管理

提供标准数据库事务控制能力，支持扩展。

### 3.9 完整性管理

实现实体、参照、自定义完整性约束检查。

### 3.10 数据库维护

支持数据库备份与还原。

### 3.11 安全性管理

用户账号管理、操作权限分配。

### 3.12 数据字典

#### 3.12.1 数据类型

|类型|说明|大小|程序类型|
|---|---|---|---|
|INTEGER|整数|4byte|int|
|BOOL|布尔|1byte|bool|
|DOUBLE|浮点数|2byte|double|
|VARCHAR|变长字符串（≤255）|n+1byte|char[n+1]|
|DATETIME|日期时间|16byte|SYSTEMTIME|
#### 3.12.2 完整性

1. **实体完整性**：PRIMARY KEY

2. **参照完整性**：FOREIGN KEY

3. **自定义完整性**：CHECK、UNIQUE、NOT NULL、DEFAULT、IDENTITY

#### 3.12.3 数据库文件规则

- 根目录：DBMS_ROOT

- 存储格式：二进制文件

- 核心文件结构：

    - 系统描述：`ruanko.db`

    - 数据库：1个文件夹 + `.tb` + `.log`

    - 表：`.tdf`（定义）、`.tic`（完整性）、`.trd`（记录）、`.tid`（索引）

#### 3.12.4～3.12.9 文件结构明细

包含数据库、表、字段、记录、完整性、索引的**文件名、结构体、存储格式**完整定义（与原文一致，已结构化整理）。
